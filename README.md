# Saham Teori (IDX)
1. Buat repo GitHub baru, upload semua isi folder ini (termasuk folder .github).
2. Tab Actions -> "Build APK" (jalan otomatis saat push).
3. Setelah hijau, unduh artifact `saham-teori-apk` -> install app-release.apk.

Fitur: grafik candlestick (geser/zoom/crosshair), harian & mingguan, 21 teori teknikal + fundamental
(manual atau otomatis), zona beli ideal + stop + target, kalkulator posisi, backtest, watchlist + alert,
portofolio, screener, IHSG, pengaturan, penjelasan teori.
